# Deployment Checklist

This document contains instructions for manually deploying and migrating the project configurations to production.

## 1. Firebase Security Rules Deployment

To enforce the private library restrictions set up in `firestore.rules`, execute the following command:

```bash
npx firebase deploy --only firestore:rules
```

**Verification:** Ensure that the rules successfully deploy and that global reads (`list: if false`) on the users collection are blocked, whilst path-based library operations (`/users/{userId}/library/{mangaId}`) work successfully.

## 2. Environment Variables Migration

Make sure that you update your production environment variables (e.g., in Vercel) according to the `.env.example` file. All Next.js and Firebase strings must be set properly before triggering the final build.

## 3. PWA Artifacts

Make sure that `public/sw.js` and other PWA artifacts generated by `next-pwa` are not tracked in version control, as they are rebuilt in production.
